# Contributing

Thank you for looking — but this project is **not accepting contributions yet**.

Pull requests will be closed without review, not out of rudeness but because
there is nothing stable to contribute against: the schema moves weekly and the
interfaces are not settled. Opening this up before that would waste your time.

Issues are welcome if you have found something factually wrong in
`DOCTRINE.md`.

When contributions open, this file will say so and will explain how.
