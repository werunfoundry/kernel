# Truths

One document per claim this instance stands behind.

The YAML file holds the machine half and the prose files hold the rest. Both
have an owner and a date, and the date is the point: a truth nobody has
confirmed in three months is reported as stale, because an ICP written once
and never revisited is how a system keeps prospecting a market that moved.

`kind` must be one a domain declares in its `truthKinds`. If the engine
refuses a kind, the domain that would understand it is not enabled.
